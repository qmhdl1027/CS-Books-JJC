## 📖 什么是 CS-Books？

**CS-Books** 是一个开源的计算机书籍合集仓库，基于 [forthespada/CS-Books](https://github.com/forthespada/CS-Books) 同步维护。我们致力于为中文开发者提供优质、免费的技术书籍资源，帮助大家系统学习计算机科学知识。

## 🚀 快速开始

### 1. 浏览书籍目录

直接访问仓库目录，按分类查找所需书籍。

### 2. 在线阅读

大部分书籍提供 PDF 或在线阅读链接，可直接点击访问。

### 3. 下载离线阅读

```bash
# 克隆仓库
git clone https://github.com/qmhdl1027/CS-Books-JJC.git
cd CS-Books-JJC
```

## 🤝 贡献指南

欢迎贡献书籍资源！请遵循以下原则：

1. **书籍来源合法** — 只收录开源或经作者授权的书籍
2. **格式规范** — 推荐 PDF / EPUB 格式，命名规范清晰
3. **分类准确** — 按已有分类目录放置，或提交 Issue 建议新分类
4. **附上来源** — 标注书籍原始链接或作者信息

**贡献方式：**
- 🌟 直接提交 Pull Request
- 📋 提交 Issue 推荐书籍
- 📢 帮助扩散，让更多人受益
